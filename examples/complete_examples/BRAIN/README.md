# brain-mesh

A two-stage workflow for generating a unified 3D computational mesh of the human brain from `.stl` surface geometries representing white matter, grey matter, and ventricles using the **Gmsh** OpenCASCADE (`occ`) kernel.

---

## Overview

This project converts anatomical `.stl` surface files into STEP geometries and then combines them into a single set of compatible mesh regions ready for numerical simulation.

1. **STL to STEP & Model Diagnostics (`brain_create_step.py`)** – Loads `.stl` files for all brain segments from `stl_files/`, reconstructs them in the OCC kernel, exports `.step` files into `step_files/`, and writes `.txt` diagnostic reports (such as bounding box information and mesh node counts) for each segment.
2. **Boolean Combination & 3D Meshing (`brain_mesh.py`)** – Imports the generated `.step` files, applies boolean operations to produce a single piece of compatible mesh segments, performs further processing, and exports the final mesh file to the current working directory.

---

## Expected Project Structure

* `stl_files/` – Input `.stl` files for the brain segments (white matter, grey matter, and ventricles)
* `step_files/` – Output `.step` files generated by `brain_create_step.py` and consumed by `brain_mesh.py`
* `brain_create_step.py` – Converts `.stl` files of all present brain segments into `.step` files and writes `.txt` model summary files
* `brain_mesh.py` – Combines the `.step` segments via boolean operations, processes the geometry, and writes the final computational mesh

---

## How to Run the Workflow

### 1. Generate STEP Files and Segment Info
Run `brain_create_step.py` first to convert every present brain segment from `.stl` to `.step`.

* Loads input `.stl` files from the `stl_files/` directory. Make sure all present brain segments are included—input paths can be adjusted at the end of the script.
* Writes the resulting `.step` files into the `step_files/` folder.
* Generates `.txt` files for each segment containing useful model details, such as bounding box dimensions and number of mesh nodes.

### 2. Build the Combined Computational Mesh
Run `brain_mesh.py` after the `.step` files have been generated.

* Reads the `.step` files from `step_files/` and uses boolean operations to turn them into one set of compatible mesh segments.
* Applies further processing to the combined geometry.
* Writes the final mesh file into the current working directory at the end of the script. You can change the output path or filename by editing the argument passed to `gmsh.write()`.
