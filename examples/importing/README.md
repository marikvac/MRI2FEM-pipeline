In this folder you will learn things important for importing data into Gmsh and then working with them.
The scripts here focus on multiple tasks you can do when handling different file types, namely **stl** and **step** files.

All of the needed input files are stored in the *step_files* and *stl_files* folders.
You can open any example script in this folder.
Input files are always specified at the beggining of the scripts.
You can read the vast ammount of comment in all of the files to get to know more about the functionality of Gmsh's importing functions.
The output files are specified at the end of each script and are stored in the corresponding folders.
